## Contenido del Portfolio

El portfolio está desarrollado con HTML5 nativo y accesible, sin CSS propio ni JavaScript:

1. **`index.html` (Inicio):** Portada con presentación personal, avatar optimizado con `<picture>`, lista de habilidades (`<dl>`), tabla de formación (`<table>`), proyectos destacados y disponibilidad.
2. **`proyectos.html` (Proyectos):** Catálogo de proyectos dividido en tres categorías con fichas detalladas, enlaces a GitHub, metodología de trabajo y tabla resumen.
3. **`sobre-mi.html` (Sobre mí):** Trayectoria vocacional, cita con `<blockquote cite>`, línea de tiempo de hitos formativos con `<time datetime>`, vídeo explicativo de redes neuronales incrustado con `<iframe>`, preguntas frecuentes con `<details>` y nivel técnico con `<meter>`.
4. **`contacto.html` (Contacto):** Formulario de contacto accesible organizado con `<fieldset>` y `<legend>`, y validación nativa HTML5.
